# synthesized-data-program

Synthesized **program-reproduction tasks**, packaged in the exact layout of
[ProgramGym-1648](https://huggingface.co/datasets/ProgramGym/programgym-1648)
(Harbor task schema 1.3) / ProgramBench, and generated by the
[program-pipeline-synthesis](https://github.com/AliaXueting/program-pipeline-synthesis)
pipeline — a mini reproduction of the Program-Env methodology from
[*ProgramGym* (arXiv:2610.13395)](https://arxiv.org/abs/2610.13395).

Each task: an AI agent receives an execute-only reference binary plus its
documentation, and must write an original codebase from scratch that
reproduces the program's behavior; a black-box behavioral test suite decides
whether the reproduction is behaviorally identical.

## Layout (identical to ProgramGym-1648)

```
<owner>--<repo>.<commit>/
├── task.toml                 # Harbor task metadata (schema 1.3)
├── instruction.md            # agent-facing reverse-engineering rules
├── environment/              # build context: Dockerfile, pinned toolchain,
│                             # docs-only workspace, execute-only reference binary
├── tests/                    # verifier build context: evaluator, per-module
│   └── blobs/tests/*.tar.gz  # behavioral test suites (pytest)
└── solution/solve.sh         # oracle ceiling check
```

## Using a task

With [Harbor](https://github.com/harbor-framework/harbor) >= 0.20 (needs
Docker):

```bash
harbor run -p /path/to/this/repo -i mvdan--sh.0e8ea6f -a <agent> -m <model>
```

Validate a task yourself (no LLM needed — runs the task's own solution):

```bash
harbor run -p /path/to/this/repo -i mvdan--sh.0e8ea6f -a oracle
# expected: reward = 1.0
```

## Quality gates applied to every task

* pass check — every test passes against the reference implementation
* double check — two isolated runs agree (flaky tests are dropped or repaired)
* dummy check — tests must fail against a no-output dummy binary
* weak-assert linter — rejects exit-code-only/tautological/short-substring assertions
* merged-suite re-validation before packaging
* oracle ceiling acceptance through the full Harbor pipeline (reward = 1.0)
